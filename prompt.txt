5. Extract all options.
6. Determine the correct answer when it is explicitly available or can be reliably derived.
7. Generate a concise but technically accurate explanation.
8. Return **only valid JSON**.

# 4. JSON VALIDITY — CRITICAL

The final response **MUST be valid JSON**.

Before responding, internally verify that:

* The output starts with `[`.
* The output ends with `]`.
* Every object has valid JSON syntax.
* Every property name uses double quotes.
* Every string uses double quotes.
* No trailing commas exist.
* No comments exist.
* No Markdown code fence exists.
* No introductory text exists.
* No text appears before or after the JSON array.
* Newlines inside strings are escaped as `\n`.
* Double quotes inside strings are escaped as `\"`.
* Backslashes are properly escaped.
* HTML contained inside strings is valid JSON-escaped text.

**Do not output Python dictionaries, JavaScript objects, YAML, Markdown, or pseudo-JSON.**
